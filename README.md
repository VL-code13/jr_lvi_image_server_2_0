# 🖼️ JR LVI Image Server 2.0 "Сервер картинок 2.0"
## 📄 Лицензия
Проект создан в учебных целях.
## Описание

Веб-сервис для загрузки, хранения и управления изображениями.  
Построен на связке **Flask + PostgreSQL + Nginx + Docker**.

## ✨ Возможности

- 📤 **Загрузка изображений** — drag-and-drop или выбор файла (JPG, PNG, GIF; до 5 МБ).
- 📋 **Список изображений** — просмотр с пагинацией (10 записей на странице).
- 🗑️ **Удаление** — удаление записи из БД и физического файла с диска.
- 🗄️ **PostgreSQL** — хранение метаданных (имя, размер, дата, тип).
- 🐳 **Docker** — развёртывание в контейнерах (Flask + PostgreSQL + Nginx).
- 💾 **Бэкапы** — скрипт для создания SQL-дампов базы данных.
- 🌐 **Nginx** — reverse proxy и отдача статических файлов.

## 🚀 Быстрый старт

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/VL-code13/jr_lvi_image_server_2_0.git
   cd jr_lvi_image_server_2_0 
   ```
2. **Конфигурация**   
Все настройки задаются через переменные окружения (.env):
- DATABASE_NAME images_db Имя базы данных PostgreSQL
- DATABASE_USER postgres Пользователь БД 
- DATABASE_PASSWORD Пароль пользователя БД
- DATABASE_HOST db Хост БД (db в Docker, localhost локально)
- DATABASE_PORT 5432 Порт БД
- DB_CONTAINER_NAME image_server_db Имя контейнера PostgreSQL
- IMAGES_DIR ./images Директория для загруженных файлов
- LOGS_DIR ./logs Директория для логов 
- BACKUPS_DIR ./backups Директория для бэкапов
3. **Запустите контейнеры**
    ```bash 
    docker-compose up -d --build
    ```
4. **Откройте в браузере:**
* Приложение: http://localhost:8080
* Flask (напрямую): http://localhost:3000

## 🌐 Основные маршруты

* **`/`** — главная страница с приветственным сообщением и ссылками на основные функции;
* **`/upload`** (`POST`) — загрузка изображений:
    * поддержка форматов: `.jpg`, `.png`, `.gif`;
    * ограничение размера: до 5 МБ;
    * генерация уникального имени файла;
    * сохранение в папку `/images` при успешной проверке;
    
* **`/images-list`** (`GET`) - Список изображений (с пагинацией).
* **`/delete/<int:id>`**(`GET`) - Удаление изображения

## 💾 Резервное копирование
* Автоматический бэкап (Docker)
```bash
python backup.py
```
Или через shell-скрипт:
```bash
bash backup.sh
```
Файлы сохраняются в backups/backup_YYYYMMDD-HHMMSS.sql.
